## Özellikler

- Kategori rafları, yatay liste, sayfalama
- Kitap araması
- Kitap detayı ve okuma ekranı
- Firebase ile giriş / kayıt
- Profil, favoriler ve kayıtlı kitaplar
- Ana sayfa yüklenirken Lottie animasyonu

## Teknolojiler

Kotlin · Jetpack (Navigation, ViewBinding) · MVVM · Hilt · Retrofit · Room · Coil · Lottie · Firebase Auth
