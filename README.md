# Library App
Discover, search, view details, and read books via the Google Books API; sign in/up and manage your profile with Firebase. Android (Kotlin).

## Features
- Category shelves, horizontal lists, pagination
- Book search
- Book detail and reading screen
- Sign in / sign up via Firebase
- Profile, favorites, and saved books
- Lottie loading animation on the home screen

## Tech Stack
Kotlin · Jetpack (Navigation, ViewBinding) · MVVM · Hilt · Retrofit · Room · Coil · Lottie · Firebase Auth
